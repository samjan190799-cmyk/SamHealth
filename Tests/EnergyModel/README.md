# Проверка расчёта энергии

Чистая логика (`Sources/EnergyModel.swift`) проверяется как обычный Swift-пакет:

```bash
cd Tests/EnergyModel
swift test
```

## Что покрыто

- Формула Миффлина — Сан-Жеора для мужчин и женщин на ручных примерах.
- Разбор пола из настроек («Мужской», «Женский», «male»), в том числе что «Женский» не принимается за мужской.
- Границы профиля (вес 30–250 кг, рост 100–230 см, возраст 14–100) и замена нечисловых значений типичными.
- Доля суток по реальной длине дня, включая дни перевода часов (23 и 25 часов).
- Базовый обмен «на сейчас»: пропорционален прошедшему времени, к полуночи сходится к суточному значению.
- Регрессия: сценарий со скриншота (11:28, съедено 173, активных 867) даёт сальдо около −1 518 ккал, а не −2 060 и −2 344.
- Знак сальдо (минус — дефицит) и перевод в граммы жира.
- Оценка калорий по шагам и защита от плохих входных данных.
- Норма калорий: личная, кратна 50, в пределах 1 200–4 500; сохранённая значение используется, если оно в пределах 1 000–6 000.
- Цели по БЖУ: при 2 200 ккал совпадают с прежними 140 / 70 / 240 г, при другой норме масштабируются.

## Что нужно проверить на iPhone

Подключение к экранам и Apple Health тесты не покрывают.

1. **Профиль.** Настройки → вес, рост, возраст, пол. От них зависят базовый обмен и норма калорий. Если профиль не заполнен, приложение берёт типичные значения (мужчина, 25 лет, 175 см, 75 кг).
2. **Одна цифра на всех экранах.** Главная (кольцо питания, карточка питания), вкладка «Питание» (энергобаланс), карточка ИИ-совета: «съедено» и норма совпадают, сальдо в питании и в ИИ-совете примерно одно и то же (различие только из-за времени между обновлениями).
3. **Утро.** С утра сальдо отрицательное, но не огромное: оно растёт по модулю в течение дня вместе с расходом, а не стоит на −2 000 с первых часов.
4. **Норма из калибровки.** Настройки → калибровка тела → «Применить нормы»: норма калорий на главной и в питании становится числом из кнопки. До этого кнопка сохраняла только воду.
5. **ИИ-совет.** Сегодняшний кэш совета сброшен (ключ v2): откройте карточку, число «Дефицит» совпадает с сальдо в питании.
