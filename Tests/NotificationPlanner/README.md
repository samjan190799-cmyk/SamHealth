# Проверка плана напоминаний

Чистая логика (`Sources/NotificationPlanner.swift`) проверяется как обычный Swift-пакет:

```bash
cd Tests/NotificationPlanner
swift test
```

## Что покрыто

- Слоты по умолчанию и ограничения настроек (часы 7–23, частота 2–8).
- Еда и вода: ежедневные повторяющиеся напоминания с идентификаторами без даты, то есть результат не зависит от дня запуска.
- Активность: скользящее окно разовых запросов на 7 дней, прошедшие слоты сегодня пропускаются, идентификаторы совместимы с отменой «на сегодня».
- Бюджет: не больше 21 разового запроса (у iOS лимит 64 ожидающих уведомления на приложение).
- Регрессия: планировщик управляет только своими идентификаторами и не трогает напоминания привычек, AI-итоги и адаптивную воду.

## Что нужно проверить на iPhone

Сами запросы iOS и фоновую доставку тесты не покрывают.

1. Открыть приложение, закрыть его (смахнуть). Через день, не открывая, убедиться, что напоминания о воде и еде пришли.
2. Создать привычку с напоминанием, перезапустить приложение несколько раз: напоминание привычки должно продолжать приходить (раньше стиралось при запуске).
3. В Настройках отключить «Активность», перезапустить приложение: активность не должна включиться снова.
4. Выдать разрешение на уведомления в настройках iOS, вернуться в приложение: напоминания должны появиться сразу, без перезапуска.
5. Шаги: набрать половину дневной цели с закрытым приложением. Уведомление о 50% придёт с задержкой (HealthKit отдаёт шаги в фоне не чаще раза в час) и только при включённом «Обновлении контента» для Forma в настройках iOS.
