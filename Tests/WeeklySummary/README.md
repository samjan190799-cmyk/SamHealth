# Проверка итогов недели

Расчёт (`Sources/WeeklySummaryLogic.swift`) не зависит от iOS и HealthKit и проверяется как обычный Swift-пакет:

```bash
cd Tests/WeeklySummary
swift test
```

Исходник подключён символьной ссылкой, поэтому тесты проверяют ровно тот код, который уходит в приложение.

## Что покрыто

| Часть | Что проверяется |
|---|---|
| Окно | последние семь дней включая сегодня; седьмой день назад ещё внутри, восьмой уже в «предыдущей неделе»; будущие даты игнорируются |
| Шаги | сумма, среднее делится на семь (а не на число записанных дней), дни с выполненной целью, лучший день (при равенстве — более свежий) |
| Сравнение | рост и падение к предыдущей неделе в процентах; нет данных за прошлую неделю — нет и сравнения; предел ±999 % |
| Тренировки | число и минуты только за окно |
| Привычки | доля выполненных отметок, не больше 100 %, без привычек — пусто |
| Дубли | два значения за один день не складываются |
| Пустая неделя | `hasData` false, итогами её не называем |
| Формат чисел | неразрывный пробел между тысячами, отрицательные числа |
