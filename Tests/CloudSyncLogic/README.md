# Проверка правил синхронизации через iCloud

Правила слияния (`Sources/CloudSyncLogic.swift`) не зависят от iOS и iCloud и проверяются как обычный Swift-пакет:

```bash
cd Tests/CloudSyncLogic
swift test
```

Исходник подключён символьной ссылкой, поэтому тесты проверяют ровно тот код, который уходит в приложение.

## Что покрыто

| Часть | Что проверяется |
|---|---|
| `latest` | побеждает более поздняя запись; при равном времени — облако; пустое облако получает локальное значение, пустое устройство — облачное |
| `maxNumber` | опыт и лучший стрик не откатываются; целые и дробные числа сравниваются вместе |
| `achievements` | открытое на любом устройстве остаётся открытым; из двух открытых — более раннее; прогресс — максимальный; чужие достижения добавляются |
| `habits` | отметки выполнения, заморозки и срывы объединяются; поля берутся у более новой версии; удалённые привычки не воскресают; привычки одного устройства сохраняются |
| `stringSet` | объединение без повторов, порядок не зависит от устройства |
| «Пустые» значения | заглушки первого запуска (нулевой опыт, пустой список) не считаются правкой и не затирают облако; нулевое число щитов — настоящее значение |
| Конверт | значение и время упаковываются и распаковываются без потерь; значение другого типа отбрасывается |
| Таблица ключей | ключи не повторяются, зависимости идут первыми, секретов и данных Apple Health в облаке нет |
