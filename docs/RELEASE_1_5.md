# Выпуск Forma 1.5

Чек-лист на день выпуска и тексты для App Store Connect. Версия в `project.yml`: 1.5.

## Что нового (русский, для поля «Что нового в этой версии»)

```
Forma стала красивее и умнее.

• Кольца везде. Шаги, питание, вода, сон, пульс, привычки и опыт показаны кольцами со свечением, как кольца Apple Fitness. Неделя колец по дням — в Тренировках и в серии дней.
• Синхронизация через iCloud. Профиль, прогресс, достижения, привычки и планы переезжают на новый телефон и на другие ваши устройства. Включается и выключается в Настройках.
• Итоги недели. Каждое воскресенье в 19:00 — шаги, тренировки, привычки и сравнение с прошлой неделей.
• Карточка «Поделиться» для наград, итогов недели, серии дней и тренировки.
• Расскажите о себе. Новый шаг при первом запуске: возраст, рост и вес для точных калорий и нормы воды.
• Новая награда: праздничный экран с медалью, очередь из нескольких наград, настоящий салют.
• Приложение для Apple Watch: исправлены типы тренировок, GPS у спортивной ходьбы и настройка бассейна.
• Исправлено: привычки больше не прячутся за фильтром времени суток.
```

## Что проверить на телефоне перед отправкой

- Чистая установка: онбординг, четыре страницы, профиль сохраняется, «Пропустить» ведёт к профилю.
- iCloud: изменить профиль и отметить привычку, подождать минуту, удалить приложение и поставить заново — данные возвращаются. Карточка «Синхронизация iCloud» в Настройках показывает «Включена».
- Главная: кольца заполняются, герой показывает калории и воду, серия дней с кольцами.
- Привычки: видны все привычки, а не только текущего времени суток.
- Тренировки: список с кольцами нагрузки, «Старт», неделя колец.
- Листы: шаги, вода, питание, пульс, сон, награды, оплата.
- Уведомление «Итоги недели» (в Настройках: «Показать итоги недели»).
- Награда: праздничный экран, кнопка «Поделиться».
- Светлая и тёмная тема, крупный шрифт.

## Перед отправкой в App Store Connect

1. **Политика конфиденциальности.** В ней добавлен абзац про iCloud, но GitHub Pages публикуется из ветки `main`. Пока рабочая ветка не влита в `main`, на сайте старый текст. Слияние в `main` запускает сборку в TestFlight (workflow срабатывает на каждый push в `main`).
2. **Возрастной рейтинг.** В App Store Connect сохранить «Реклама = Да» (отказ 2.3.6 по версии 1.4).
3. **Версия.** Создать версию 1.5, выбрать загруженный билд, вставить тексты выше.
4. **App Privacy.** Менять не нужно: данные iCloud остаются в аккаунте пользователя, разработчик к ним доступа не имеет.
5. **Заметки для рецензента.** Ничего особенного не требуется. Служебные инструменты (панель рекламы, пароль PRO) в обычную сборку не попадают — это проверяет Release Guard.
6. **Сборка для App Review** должна быть обычной (без `internal_tools`): запускается по умолчанию.
