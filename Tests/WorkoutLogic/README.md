# Проверка логики тренировки

Чистая логика (`Sources/WorkoutLogic.swift`) не зависит от iOS и проверяется как обычный Swift-пакет:

```bash
cd Tests/WorkoutLogic
swift test
```

Исходник подключён символьной ссылкой, поэтому тесты проверяют ровно тот код, который уходит в приложение.

## Что покрыто

| Часть | Что проверяется |
|---|---|
| `WorkoutClock` | время идёт по часам, а не по тикам: блокировка экрана на 5 минут даёт 301 с, а не 2; пауза и возобновление; неподвижное время отдельно от активного; предохранитель на забытую тренировку |
| `CustomWorkoutProgress` | регрессия «пропускается первый подход следующего упражнения»; каждый запланированный подход проходится ровно один раз; повторный конец отдыха безопасен; «подход выполнен» во время отдыха игнорируется |
| `WorkoutRecordingPolicy` | тренировки короче 60 с не записываются и не дают XP |
| `WorkoutDuplicateRule` | когда две записи считаются одним занятием: тот же UUID, старт в пределах 90 с (строго меньше), длительность в пределах 2 мин, совместимый тип без учёта регистра |
| `WorkoutRewardPolicy` | опыт за занятие — 150 один раз (раньше 100 + 150 = 250); повтор записи с часов, импорт и ручные записи опыта не дают |

## Что нужно проверить на iPhone

Опыт и дубликаты:

- Завершить тренировку на iPhone дольше минуты: на итоговом экране `+150 XP`, а не `+250`.
- Тренировка с Apple Watch: после синхронизации ровно один раз `+150 XP`; повторная отправка того же занятия опыта и калорий не добавляет.
- Импорт тренировок из CSV: в «Здоровье» они появляются с исходными датами (не «сегодня»), XP не меняется, повторный импорт того же файла не создаёт копий.

Интеграцию с `WorkoutTracker`, `WorkoutsView` и HealthKit тесты не покрывают:

1. Запустить бег (или силовую), заблокировать экран на 2–3 минуты, разблокировать: время должно быть настоящим, а не «замершим».
2. Йога, силовая или планка с телефоном на полу: автопауза не включается, время идёт, кнопки автопаузы на экране нет.
3. Бег или ходьба: кнопка «Автопауза» есть и работает.
4. Личная тренировка с несколькими упражнениями: после отдыха между упражнениями первое упражнение нового блока идёт с подхода 1.
5. Старт и сразу «Завершить»: подтверждение, затем сообщение «Слишком короткая тренировка», записи в «Здоровье» нет, XP нет.
6. Тренировка дольше минуты: перед завершением спрашивает подтверждение, затем сохраняется как раньше.
